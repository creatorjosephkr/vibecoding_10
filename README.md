# 저장소 활용 목적
본 저장소는 서울디지털대학교의 '바이브 코딩' 과정에서 진행하는 프로젝트 소스 코드를 올리고 관리하기 위한 곳입니다. 

# 프로젝트 소개
* 강의주차: 7주차 2교시 myPomodoro 만들기
* 기능
  - 25분 집중 5분 휴식 타이머
  - 백색소음 4가지 (파도, 빗소리, 새소리, 장작불)
  - 백색소음 무음 전환 기능
  - 볼륨 조절 기능
  - 일시정지
  - 세션유지 기능(브라우저를 닫았다가 다시 열면 이어서 진행)
  - 라이트/다크 모드
